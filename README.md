A faithful `mend` CLI: one patch tool that applies four edit formats (unified diff, SEARCH/REPLACE, V4A and JSON edits) to a tree of text files, with three-tier line matching, safe paths, `--check`, `--strict` and all-or-nothing writes.

## Run it

```sh
node main.ts [OPTIONS] [PATCH]
```

Options: `--format=auto|unified|search-replace|v4a|json`, `--check`, `--strict`, `--`. With no PATCH (or `-`) the patch is read from stdin. Node 22 and the standard library are the only requirements.
